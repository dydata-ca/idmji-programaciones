# Validación previa a publicación

## Revisión de transcripción
Se detectaron y retiraron del JSON publicado **etiquetas de calendario de diciembre** que habían sido interpretadas erróneamente como nombres de colaboradores en noviembre:

- 2026-11-25 / Interpretación EN: `Dec 1.`
- 2026-11-26 / Interpretación EN: `Dec 2., Dec 3.`

## Incidencias que requieren revisión humana
- 2026-11-02 / Interpretación EN: Nombre duplicado: verificar PDF
- 2026-11-05 / Interpretación EN: Sin nombre consignado

La ausencia de nombre en una función o un nombre duplicado **no se corrige por inferencia**; contrastar contra los PDF originales antes de hacer público el sitio.
